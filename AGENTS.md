# AGENTS.md

The binding instructions for every AI agent working in this repository are in [CLAUDE.md](CLAUDE.md).
Read that file completely before you change anything. It is the single authoritative source.

The four hard rules are repeated here so that no agent can miss them:

1. Everything that lands in the project is in English: code, code comments, Markdown files, ADRs, commit messages, branch names, configuration keys, log and error messages, notification texts, and issue and pull request texts.
2. Code comments are always in English, without exception.
3. ADRs and all other Markdown files are always in English.
4. No AI agent appears as a co-author anywhere: no `Co-Authored-By` trailer in commits, and no "Generated with ..." line or similar attribution in commits, pull requests, or files.

The maintainer usually writes in German. Chat replies may be in German; project content never is.

If this file and CLAUDE.md ever disagree, CLAUDE.md wins.
